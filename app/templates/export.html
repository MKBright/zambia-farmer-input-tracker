About the summary files

Farmer summary has one row for each crop a farmer planted. The yield column is kilograms per hectare. Inputs used are listed in one cell, already converted to kilograms.

District summary has one row for each district and crop. It does not include an “all districts” row, so you can add the rows in a spreadsheet without counting anyone twice. The on-screen report has the combined view.
